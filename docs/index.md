## Get started

![](media/index/microsoft-entra-id-color.png)[Microsoft Entra ID](/en-us/entra/identity/)
Manage user identities and control access to your apps, data, and resources.

![](media/index/microsoft-entra-agent-id.png)[Microsoft Entra Agent ID](/en-us/entra/agent-id/)
Build, discover, govern, and protect agent identities.

![](media/index/id-protection-color.png)[Microsoft Entra ID Protection](/en-us/entra/id-protection/)
Identify and address identity risks in your organization.

![](media/index/id-governance-color.png)[Microsoft Entra ID Governance](/en-us/entra/id-governance/)
Protect, monitor, and audit access to critical assets while ensuring employee productivity.

![](media/index/external-id-color.png)[Microsoft Entra External ID](/en-us/entra/external-id/)
Secure and manage any external user, including customers and partners, in your organization.

![](media/index/internet-access-color.png)[Microsoft Entra Internet Access](/en-us/entra/global-secure-access/)
Protect access to all internet, SaaS, and Microsoft 365 apps and resources with an identity-centric Secure Web Gateway.

![](media/index/private-access-color.png)[Microsoft Entra Private Access](/en-us/entra/global-secure-access/)
Secure access to all private apps and resources with identity-centric Zero Trust Network Access (ZTNA).

![](media/index/verified-id-color.png)[Microsoft Entra Verified ID](/en-us/entra/verified-id/)
Enable more secure interactions while respecting privacy with an industry-leading global platform.

![](media/index/workload-id-color.png)[Microsoft Entra Workload ID](/en-us/entra/workload-id/)
Secure identities for apps and services and their access to cloud resources.

![](media/index/copilot-color.png)[Security Copilot + Microsoft Entra](/en-us/entra/security-copilot/security-copilot-in-entra)
Use the power of Security Copilot for identity and network security.
