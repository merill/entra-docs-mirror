# Govern on-premises users that are provisioned to Active Directory with Microsoft Identity Manager | Microsoft Learn

**Scenario:** Manage on-premises users that are provisioned to Active Directory with Microsoft Identity Manager.

[![Conceptual drawing showing MIM provisioning.](media/provision-microsoft-identity-manager-to-active-directory/provision-microsoft-identity-manager-to-active-directory.png)](media/provision-microsoft-identity-manager-to-active-directory/provision-microsoft-identity-manager-to-active-directory.png#lightbox)

If you have integration scenarios for users and groups that aren't in scope of Microsoft Entra ID scenarios, then you may want to consider using the [Microsoft Identity Manager](/en-us/microsoft-identity-manager/microsoft-identity-manager-2016). Be aware that the end of [support date](/en-us/microsoft-identity-manager/microsoft-identity-manager-2016#support-update-for-microsoft-entra-id-p1-or-p2-customers) for Microsoft Identity Manager 2016 is January 9, 2029.

For detailed information on how to provision users to Active Directory using Microsoft Identity Manager, see [How do I provision users to AD DS](/en-us/microsoft-identity-manager/mim-how-provision-users-adds).
