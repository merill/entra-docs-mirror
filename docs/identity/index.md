# Microsoft Entra ID documentation

Use Microsoft Entra ID to manage user identities and control access to your apps, data, and resources.

## Getting started

![](media/index/entra-id.svg)[What is Microsoft Entra ID?](../fundamentals/what-is-entra)

![](media/index/authentication.svg)[Authentication](authentication/overview-authentication)

![](media/index/enterprise-applications.svg)[Application management](enterprise-apps/what-is-application-management)
Develop, add, or connect an app to Microsoft Entra ID and manage access.

![](media/index/role-based-access-control.svg)[Role-based access control](role-based-access-control/custom-overview)
Manage administrator permissions and apply the principle of least privilege using Microsoft Entra role-based access control.

![](media/index/users.svg)[User management](users/directory-overview-user-model)
Manage users and groups, assign licenses, and manage domain names.

![](media/index/conditional-access.svg)[Conditional Access](conditional-access/overview)
Control access to resources by enforcing policies based on user, location, device, and more.

![](media/index/devices.svg)[Device identity](devices/overview)
Register and join devices to Microsoft Entra ID for device management and Conditional Access.

![](media/index/hybrid-identity.svg)[Hybrid identity](hybrid/whatis-hybrid-identity)
Create a user identity that can access both on-premises and cloud resources.

![](media/index/application-provisioning.svg)[Application provisioning](app-provisioning/user-provisioning)
Create and manage user identities in applications by provisioning from Microsoft Entra ID.

![](media/index/enterprise-applications.svg)[Application proxy](app-proxy/overview-what-is-app-proxy)
Provide secure remote access and cloud scale security to your private applications.

![](media/index/managed-identities.svg)[Managed identities for Azure resources](managed-identities-azure-resources/overview)
Create an application identity that can connect to resources using Microsoft Entra authentication.

![](media/index/enterprise-applications.svg)[Application integration](saas-apps/tutorial-list)
Integrate cloud-enabled, software as a service (SaaS) apps with Microsoft Entra ID.

![](media/index/monitoring-health.svg)[Monitoring and health](monitoring-health/overview-monitoring-health)
Use logs and reports to determine usage of your apps and services, detect risks, and troubleshoot issues.

![](media/index/multitenant-organizations.svg)[Multitenant organizations](multi-tenant-organizations/overview)
Collaborate across tenants within your organization.

![](media/index/domain-services.svg)[Domain services](domain-services/overview)
Move legacy apps to managed domains in the cloud while preserving user accounts, groups, and access.

![](media/index/domain-services.svg)[Tenant governance](../id-governance/tenant-governance/overview)
Discover related tenants, manage cross-tenant governance relationships, monitor tenant configuration and secure tenant creation.

![](media/index/azure-ad-b2c.svg)[Azure Active Directory B2C](/en-us/azure/active-directory-b2c/)
