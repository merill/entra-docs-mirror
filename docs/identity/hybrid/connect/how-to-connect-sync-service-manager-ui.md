# Microsoft Entra Connect Sync: Synchronization Service Manager UI - Microsoft Entra ID | Microsoft Learn

![Screenshot that shows the Synchronization Service Manager U I.](media/how-to-connect-sync-service-manager-ui/ssmui.png)

The **Synchronization Service Manager** UI is used to configure more advanced aspects of the sync engine and to see the operational aspects of the service.

You start the **Synchronization Service Manager** UI from the start menu. It is named **Synchronization Service** and can be found in the **Microsoft Entra Connect** group.![Sync Service Manager](media/how-to-connect-sync-service-manager-ui/startmenu.png)
