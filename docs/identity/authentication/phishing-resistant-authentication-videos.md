# Phishing resistant authentication in Microsoft Entra ID - Microsoft Entra ID | Microsoft Learn

In this video series, we guide you through the basics of phishing-resistant authentication methods in Microsoft Entra ID. Multifactor authentication is one of the most effective controls to prevent an adversary from gaining access to sensitive information.

Watch the following videos, or visit the [Phishing Resistant Authentication in Microsoft Entra ID](https://www.youtube.com/playlist?list=PL3ZTgFEc7LysTnItcN7SJnJ6wpPJif2-k) video series, for guidance on how to configure phishing-resistant multifactor authentication methods.

To learn more, see [Windows Hello for Business](/en-us/windows/security/identity-protection/hello-for-business/), [certificate-based authentication](concept-certificate-based-authentication), and passkeys formally [FIDO2](how-to-authentication-passkeys-fido2) security keys. In addition, learn about [Microsoft Entra Conditional Access](../conditional-access/overview), which brings signals together to inform decision making, and enforces organizational policies.
