# How to remove a user's access to an application in Microsoft Entra ID - Microsoft Entra ID | Microsoft Learn

This article provides several scenarios for removing user access to applications in Microsoft Entra ID.

## Scenarios

### Remove a specific user’s or group’s assignment to an application

To remove a user or group assignment to an application, follow the instructions in [Remove a user or group assignment from an enterprise app in Microsoft Entra ID](assign-user-or-group-access-portal).

### Disable all user access to an application

To disable all user sign-ins to an application, follow the instructions in [Disable user sign-ins for an enterprise app in Microsoft Entra ID](disable-user-sign-in-portal).

### Delete an application entirely

To delete an application from your Microsoft Entra tenant, follow the guidance in the [Quickstart Series on Application Management](delete-application-portal).

### Disable all future user consent operations in any application

To disable all future user consent operations in an application, follow the instructions in [Configure how end-users consent to applications](configure-user-consent).
