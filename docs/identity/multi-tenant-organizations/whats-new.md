# What's new in multitenant organization documentation - Microsoft Entra ID | Microsoft Learn

## Overview

This article provides information about new features and documentation improvements in multitenant organizations for Microsoft Entra ID.

## 2026

| Date | Area | Description |
| --- | --- | --- |
| August 2026 | Cross-tenant synchronization | Revised configuration steps for updated Overview, Attribute mapping, Provisioning configuration, and Basics settings pages. See [Configure cross-tenant synchronization](cross-tenant-synchronization-configure). |
| March 2026 | Cross-tenant synchronization | Added support for security group synchronization (same cloud) in preview. See [Group synchronization](cross-tenant-synchronization-overview#group-synchronization) and [Configure cross-tenant synchronization](cross-tenant-synchronization-configure?pivots=same-cloud-synchronization). |

## 2025

| Date | Area | Description |
| --- | --- | --- |
| June 2025 | Cross-tenant synchronization | Cross-cloud synchronization support status update. See [Configure cross-tenant synchronization](cross-tenant-synchronization-configure?pivots=cross-cloud-synchronization). |
| June 2025 | Cross-tenant synchronization | Cross-cloud synchronization preview. See [Configure cross-tenant synchronization](cross-tenant-synchronization-configure?pivots=cross-cloud-synchronization). |
| May 2025 | Multitenant organizations | Updated beta references to general availability for PowerShell and Microsoft Graph APIs. See [Configure a multitenant organization using PowerShell or Microsoft Graph API](multi-tenant-organization-configure-graph). |

## 2024

| Date | Area | Description |
| --- | --- | --- |
| May 2024 | Multitenant organizations | Capabilities and overview updates. See [Multitenant organization capabilities in Microsoft Entra ID](overview) and [What is a multitenant organization in Microsoft Entra ID?](multi-tenant-organization-overview). |
| April 2024 | Multitenant organizations | General availability of multitenant organization features. See [What is a multitenant organization in Microsoft Entra ID?](multi-tenant-organization-overview). |
| January 2024 | Cross-tenant synchronization | Refresh steps and screenshots. See [Configure cross-tenant synchronization](cross-tenant-synchronization-configure). |
| January 2024 | Cross-tenant synchronization | Added directory extensions. See [Map directory extensions in cross-tenant synchronization](cross-tenant-synchronization-directory-extensions). |
