# Quickstart: Add sign in to a Node.js/Express web app - Microsoft Entra External ID | Microsoft Learn

> 
> In this quickstart, you download and run a code sample that demonstrates how a Node.js/Express web app can sign in users with Microsoft Entra External ID.

1. Make sure you've installed [Node.js](https://nodejs.org/en/download/).
2. Unzip the sample app
3. In your terminal, locate the sample app folder, then run the following commands:

    ```console
    cd App && npm install && npm start
    ```
4. Open your browser, visit `http://localhost:3000`, select **Sign-in**, then follow the prompts.
