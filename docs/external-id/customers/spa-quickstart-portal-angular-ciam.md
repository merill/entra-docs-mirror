# Quickstart: Add sign in to an Angular SPA - Microsoft Entra External ID | Microsoft Learn

> 
> In this quickstart, you download and run a code sample that demonstrates how an Angular single-page application (SPA) can sign in users with Microsoft Entra External ID.

1. Make sure you've installed [Node.js](https://nodejs.org/en/download/).
2. Unzip the sample app.
3. In your terminal, locate the sample app folder, then run the following commands:

    ```console
    cd SPA && npm install && npm start
    ```
4. Open your browser, visit `http://localhost:4200`, select **Sign-in**, then follow the prompts.
